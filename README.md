# iM PASS — 외국인 근로자 신원·자격 지갑

2026 AI Blockchain Challenge in Daegu 출품 프로토타입.
외국인 근로자가 자기 **체류·취업 자격**을 지갑에 두고, 필요한 곳에 필요한 것만 골라 제출하며,
그 자격에서 바로 이어지는 **금융 서비스**까지 한 앱에서 쓰는 구조를 구현했다.

세 개의 사용자 화면으로 나뉜다.

| 화면 | 쓰는 사람 | 하는 일 |
|---|---|---|
| **iM PASS 근로자** | 외국인 근로자 (모바일) | 지갑 발급, 자격 제출 QR, 근태, 퇴직급여, 송금·적금, 보험 |
| **iM PASS 사업자** | 사업장 담당자 (태블릿·키오스크) | 자격 확인, 근태 등록, 거점병원 진료 접수 |
| **iM PASS 은행·기관** | 은행·발급기관 직원 (데스크톱) | 자격 발급·철회·복구, 영업 대시보드, 보험 접수함 |

---

## 1. 이 서비스가 푸는 문제

외국인 근로자의 서류는 **기관마다 흩어져 있다.** 체류자격은 출입국, 고용이력은 고용센터,
건강진단은 의료기관, 한국어 시험은 산업인력공단에 있다. 사업장이 한 사람을 채용하려면
이 기관들을 따로 확인해야 하고, 근로자는 같은 서류를 몇 번씩 떼야 한다.

이 프로토타입은 **카드를 지갑에 쌓아두지 않는다.** 제출할 때마다 기관에 다시 물어
그 순간의 값으로 QR을 만든다. 그래서 "낡은 증명서"라는 것이 존재하지 않는다.
블록체인에는 개인정보를 올리지 않고 **자격의 유효/철회 상태 해시만** 기록한다.

### 은행이 이 일을 하는 이유
근로자는 급여를 받으려면 어차피 은행 창구에 가고, 그 자리에서 여권·외국인등록증 대조가
법적으로 이미 일어난다. **절차를 늘리지 않는 유일한 접점**이 은행이다.
카카오 인증서가 통신사 본인확인 위에 세워지듯, 이 지갑은 은행 실명확인 위에 세워진다.
은행이 보증하는 것은 "이 지갑이 이 사람의 것"이라는 사실 **하나뿐**이고,
체류자격은 출입국이, 고용이력은 고용센터가 답한다.

사업 모델은 B2B2C다. **사업장 한 곳과 계약하면 근로자 수백 명이 한 번에 온다.**
은행이 얻는 것은 급여계좌, 같은 급여일에 같은 통화로 나가는 송금 수요(환헤지 규모),
그리고 기업 접점이다.

## 3. 실행

```bash
run_all.bat            # 가상환경 생성 → 의존성 설치 → 서버 기동
```

또는 수동으로:

```bash
cd backend
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

접속: `http://127.0.0.1:8000/home.html`
API 문서: `http://127.0.0.1:8000/docs` · 헬스체크: `http://127.0.0.1:8000/health`

`.env` 없이도 **온체인 시뮬레이터**로 즉시 돈다. 실제 체인에 붙이려면
`backend/.env`에 `RPC_URL` · `CONTRACT_ADDRESS` · `ADMIN_PRIVATE_KEY`를 넣는다.
번역을 LLM까지 쓰려면 `GEMINI_API_KEY`를 함께 넣는다(없으면 내장 사전으로 폴백).

> `google-generativeai` 의존성 트리가 커서 첫 설치가 몇 분 걸린다. `pip install`에
> `-q`가 붙어 있어 진행 표시가 없으니 멈춘 것으로 오해하지 말 것.

## 5. 발급기관 8곳

`REAL`은 자기 정보의 원천 주체라 실서비스에서도 그대로 발급하는 곳,
`MOCK`은 Phase 2 협력 인터페이스 제안이다. **이 구분을 화면에서 지우지 말 것.**

| 기관 | 구분 | 제공 |
|---|---|---|
| 출입국·외국인청 | MOCK | 체류자격·신원 |
| 고용노동부 고용센터 | MOCK | 고용이력·사업장 변경 |
| **iM뱅크** | **REAL** | 급여계좌 실명확인 |
| 지정 의료기관 | MOCK | 건강진단 유효기간 (진단 내용은 제공하지 않음) |
| 한국산업인력공단 | MOCK | EPS-TOPIK·취업교육 |
| Q-Net | MOCK | 국가기술자격 |
| 안전보건공단 | MOCK | 안전보건교육 이수 |
| 국립국제교육원 | MOCK | TOPIK·사회통합프로그램 |

목적에 따라 묻는 기관이 달라진다. `employer`는 8곳 전부, `insurance`는 3곳,
`hospital`은 출입국과 의료기관 2곳만 조회한다.

## 6. 주요 기능

### 6-1. 지갑 발급 (최초 1회)
1. **창구 실명확인** — `bank_kyc.json`에 없으면 여기서 멈춘다.
2. **단말 키 생성** — 브라우저가 ECDSA P-256 키 쌍을 만들고 **개인키는 단말에 남는다.**
3. **출입국 조회(필수)** — 기록이 없거나 체류자격이 말소면
   `지갑을 발급할 수 없습니다 (사유: 체류자격 말소)`로 중단한다.
4. **나머지 기관 조회 + 온체인 등록** — 기록이 없는 기관은 빈칸으로 두고 진행한다.

### 6-2. 제출 QR
수령처(사업장·병원·은행·보험사)를 고르면 **그곳에 필요한 항목만** 담긴 QR을 만든다.
제출할 때마다 기관에 다시 묻고, QR은 **60초 뒤 만료**된다. 카드를 미리 받아 쌓지 않는다.
단말 키로 서명하므로 남의 지갑으로 대신 낼 수 없다.

검증 실패 유형: `SIGNATURE_INVALID`(위변조) · `TARGET_MISMATCH`(수령처 불일치) ·
`REVOKED`(온체인 철회) · `EXPIRED`(QR 만료).

### 6-3. 근태
사업장 입구 스캐너가 QR을 읽으면 출근, 다시 읽으면 퇴근이다. **시각은 회사 근태 시스템이 찍는다.**
근태 조작 방지(양방 서명·온체인 앵커링)는 의도적으로 범위 밖에 두었다 —
여기서 푸는 문제는 근로감독이 아니라 **고용 적격 여부**이고, 은행이 사업주를 감시하는
도구를 팔면 도입 자체가 되지 않기 때문이다.

### 6-4. 퇴직급여 — 체류자격에 따라 갈린다
- **E-9·H-2 → 출국만기보험.** 사업주가 월 통상임금의 8.3%를 납입하고(외고법 제13조),
  보험금은 **출국일부터 14일 이내** 지급된다. 근로자가 고를 상품이 없으므로 선택 버튼도 없다.
- **E-7 등 → 퇴직연금 DC.** 근로자가 운용상품을 고르고 **언제든 바꿀 수 있다.**
  운용지시를 바꿔도 **과거 수익은 소급되지 않는다** — 바꾼 시점 잔액을 동결하고
  그 뒤 기간에만 새 수익률을 적용한다. 그래서 상품을 눌러도 현재 잔액은 그대로이고
  **귀국 시 예상 금액만** 움직인다. 2023년 시행된 사전지정운용제도(디폴트옵션)도 반영했다.

### 6-5. 금융생활
① 매달 송금액 설정 → ② 퇴직급여 → ③ 귀국 목표 적금 → ④ 해외송금 순으로 한 화면에 쌓인다.
**환율 보장**은 같은 급여일에 같은 통화로 나가는 송금을 묶어 헤지 규모를 만드는 구조다.
헤지 대상은 **원화와 근로자 본국 통화 사이의 환율**이다(베트남 근로자라면 원화-동화). 본국 통화의 선물환 시장이 얕아 직접 헤지가 어려우면 움직임이 비슷한 통화로 대신 헤지한다(프록시 헤징 — 예: 베트남 동 대신 태국 바트). 헤징은 이런 방식이 가능하다는 **사례**로 보여줄 뿐이며, 하나의 고정된 방법으로 정해두지 않는다.

**등급 A/B의 기준은 하나다 — "국내 은행간 외환시장에서 원화와 직접 거래되는 통화인가?"**
시장 깊이를 우리가 추정하지 않고, 누구나 확인할 수 있는 제도적 사실 하나로 나눈다.

| 등급 | 조건 | 헤지 방법 | 수수료(가정) |
|---|---|---|---|
| A | 원화 직거래 통화 — 미국 달러(원/달러 시장), 중국 위안(원/위안 직거래시장, 2014-12-01 개설) | 원화-본국통화를 한 번에 | 10,000원 |
| B | 그 밖의 통화 | 원화-달러 + 달러-본국통화 두 번. 달러-본국통화 구간이 얕으면 비슷한 통화로 프록시 | 20,000원 |
| C | 등급과 무관 — 월 30만 원 미만이거나 막아 주는 변동 폭 < 수수료 | 권하지 않음 | — |

원화-루피아 현지통화 직거래 체제(LCT, 2024-09-30 시행)는 무역결제용 체제이지 은행간 직거래 시장이 아니므로 A로 올리지 않았다.
개인 50만원은 최소 계약 단위도 안 되지만 수백 명이면 규모가 나오고, **그 수요 예측이 지갑에서 나온다.**
근로자는 파생 계약 당사자가 아니라 은행과 단순 예약 계약을 맺는다.
송금액이 작아 막아 주는 변동 폭이 수수료보다 작으면 **권하지 않는다** — 안 팔아야 할 사람에게 안 파는 것이 핵심이다.

### 6-6. 알림 (잠금화면)
헤더의 종을 누르면 폰 잠금화면으로 바뀌고 그 위에 푸시가 떠 있다.
근로자가 이 알림을 실제로 보는 자리가 잠금화면이기 때문이다.
지금 뜨는 알림은 **체류 만료 임박 하나뿐**이다. 연장 허가가 만료 4개월 전부터 가능하므로
120일을 기준으로 잡았고, 30일 이하는 급한 단계로 올라간다.
은행이 절차를 대행하거나 법적 결과를 단정하지 않는다 — 날짜를 돌려주고 어디로 가야 하는지까지만 말한다.

### 6-7. 다국어
한국어·영어·베트남어·인도네시아어·우즈베크어·중국어·태국어 **7개 언어.**
두 경로가 겹쳐 돈다. `data-i18n` 키가 붙은 문구는 **내장 사전**이 즉시 바꾸고,
키가 없는 문구는 `POST /api/translate`(Gemini)가 채운다. 키가 없으면 사전만으로 폴백한다.
**이름·계좌번호·외국인등록번호·payload·환자 정보에는 `data-no-translate`가 붙어 있다** — 번역 API로 나가지 않는다.
언어 선택기는 런처와 근로자 폰 화면에만 둔다(사업장·관리자 화면은 국내 직원용).

## 7. API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/health` | 체인 연동 모드 확인 |
| GET | `/agencies` | 발급기관 목록과 목적별 조회 대상 |
| POST | `/wallet/bank-verify` | 창구 실명확인 |
| POST | `/wallet/register` | 단말 공개키 등록 + 지갑 발급 |
| POST | `/credentials` | 자격증 발급 + 온체인 등록 |
| GET | `/wallet/{cid}` | 지갑 상태·기관 조회 기록·이직 도시에·**알림** |

## 10. 구현 범위에서 의도적으로 뺀 것

프로토타입 시연 범위라 **계산에 넣지 않았다.** 빠졌다는 사실은 코드 주석과 화면 문구에 밝혀 두었다.

- **주휴수당** — 월 근로시간을 `21.7일 × 8시간 = 173.6시간`으로 잡는다.
  최저임금 월 환산 기준은 주휴 8시간을 더한 209시간이라, 예상 급여가 실제보다 약 17% 낮다.
  이 값이 출국만기보험료·퇴직연금 부담금까지 전파된다.
- **4대보험 공제와 소득세** — "한국에서 쓰고 남는 돈"은 세전 기준이다.
- **이자소득세 15.4%** — 적금 만기 예상액은 세전이다.
- **국민연금 반환일시금·귀국비용보험금** — 받을 수 있는 돈이지만 **공적 제도라 은행이
  끼어들 자리가 아니라고 보고** 귀국정산에서 뺐다. 이 화면은 은행이 직접 제공하는 상품만 센다.
- **법정 퇴직금과 출국만기보험금의 차액** — 계산해 보여 주다가 걷어냈다.
  은행 앱이 "회사가 돈을 덜 줬다"고 말하는 구조가 되고, 근사값으로 분쟁을 유발하기 때문이다.
  대신 "기준이 다를 수 있으니 퇴직 전에 확인해 보시라"고만 안내한다.
- **사업장 변경의 권역·업종 제한** — 시행 범위가 자료마다 달라 넣지 않았다.
- **근태 조작 방지** — 6-3 참조.

## 11. 개발 시 주의

- **시드를 바꾸면 서버를 재시작해야 한다.** `--reload`는 `.py`만 감시하고,
  발급된 지갑은 발급 시점의 기관 조회 결과를 들고 있다.
- `i18n.js`는 최상위 `const I18N`이다. **`window.I18N`은 항상 `undefined`**이므로
  `typeof I18N !== "undefined"`로 확인해야 한다.
- 화면 위에 덮는 요소에 `position: fixed`를 쓰지 않는다. 데스크톱에서 목업 폰 밖으로 샌다.
  `.phone` 안에서 `absolute`로 덮는다.
- `alert()` 대신 `window.imwpNotify()`를 쓴다. `alert`는 목업 폰 밖에 뜨고 화면을 멈춘다.
- 누르면 아무 동작도 안 하는 버튼을 만들지 않는다. 미구현은 `Phase 2` 배지로 표시만 한다.
